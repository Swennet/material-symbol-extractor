# Intended project commands
- `npm test`: run the Vitest suite once.
- `npm run test:watch`: run Vitest in watch mode.
- `npm run test:coverage`: run Vitest with enforced V8 coverage thresholds.
- `npm run check`: run ESLint, Prettier checking, Vitest coverage, and publint.
- `npm pack --dry-run`: inspect publish contents.
- `npm pack`: create the tarball used for the minimal-fixture smoke test.
- Package files do not exist yet; consult the approved implementation plan before assuming commands are available.
